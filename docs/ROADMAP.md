## งานโครงสร้าง — สำคัญกว่าที่เห็น

**แยก `src/base.html` ออกเป็นโมดูลจริง**

ตอนนี้ 11,000 บรรทัดในไฟล์เดียว แก้ผ่านสคริปต์ replace ที่ต้องหา string ตรงเป๊ะ
มันมี assert กันพลาดและใช้งานได้ แต่เคยลบผิดบล็อกมาแล้วหนึ่งครั้ง

แนวทางที่แนะนำ ทำทีละขั้นโดยรันเทสต์ทุกขั้น:

1. ดึง CSS ออกเป็น `src/styles.css`
2. ดึงโค้ดออกเป็น ES module ทีละก้อน โดยเริ่มจากก้อนที่ไม่มีใครเรียก
   (DXF writer, storage, math)
3. ใช้ bundler ง่าย ๆ (esbuild) แล้ว inline กลับเป็นไฟล์เดียวตอน build
4. เมื่อ `base.html` เหลือแต่ HTML → เลิกใช้ `scripts/build.py`

**เงื่อนไข:** ชุดเทสต์ต้องผ่านครบทุกขั้น ถ้าขั้นไหนทำให้พัง ให้ย้อนขั้นนั้น
ไม่ใช่เดินหน้าต่อ

## บิลด์ทดลองที่ถอดออกไป

`DM_B_experimental.html` มีของที่เคยทำแล้วถอดออกตามคำขอ หยิบกลับมาได้ทีละอย่าง:

- สวิตช์ ANSI ที่ควบคุมการทำงานจริง + สีตามธีม
- ข้อความบอกขนาด mm ใต้ช่อง Size
- สัญลักษณ์มุมฉายเป็นเส้นลูกโซ่ ย่อ 80%
- พรีวิวที่ย่อตามความกว้างและรอ layout ก่อนวาด (แก้อาการเบลอ)
- **import ไม่วาดทับ — รอ STYLIZE** (ข้อนี้แนะนำให้เอากลับมาก่อนเพื่อน)
- เส้นตัดเป็น phantom line
- ไอคอนปุ่ม Add Pointer

**ถ้าจะหยิบกลับ ให้ทำทีละอย่าง แล้วรันเทสต์** — การรวมหลายอย่างในรอบเดียวคือสิ่งที่
ทำให้แยกไม่ออกว่าอะไรพัง
