# สถาปัตยกรรม

## หลักคิดกลาง: โมเดล ไม่ใช่รอยวาด

ทุกสิ่งที่โปรแกรมเข้าใจ ถูกเก็บเป็น **object ที่รู้ว่าตัวเองประกอบด้วยอะไร**
ไม่ใช่กองเส้นที่ต้องเดาความหมายทีหลัง

```
ไฟล์ DXF ──► อ่านเป็นโมเดล ──► วาดจากโมเดล ──► เขียนโมเดลกลับออกไป
             (dimension,        (ทุกเส้นคำนวณ    (DIMENSION entity
              section,           จากโมเดล)        จริง ๆ)
              balloon)
```

ผลที่ตามมาจากโครงนี้:

- **กด STYLIZE กี่ครั้งก็ได้ผลเดิม** เพราะเป็นการตั้งค่าแล้ววาดใหม่ ไม่ใช่การนวดสะสม
- **ลากยังไงก็ไม่หลุดจากกัน** เพราะเส้นชี้กับหัวลูกศรไม่ได้ถูกเก็บแยกจากโมเดล
- **ค่าที่แสดงเปลี่ยนตามการวัด** ไม่ใช่ข้อความที่ตรึงไว้
- **export ได้ของจริง** เพราะมีโมเดลให้เขียน ไม่ต้องเดาจากเส้น

## ชั้นของข้อมูล

```
project (บันทึกใน IndexedDB)
└── page (sheet)
    ├── dxf                  ← "แบบ" — แหล่งความจริง
    │   ├── polys/texts/solids/hatches      เส้นและตัวหนังสือ
    │   ├── dims[]           โมเดลไดเมนชั่น
    │   ├── secs[]           โมเดลเครื่องหมายหน้าตัด
    │   └── balloons[]       โมเดลลูกศรชี้พร้อมหมายเลข
    └── objects[]            ← สร้างขึ้นจาก dxf สำหรับการเลือก/ลาก
```

**`objects` ไม่ถูกบันทึก** — สร้างคืนตอนเปิดเสมอ การเก็บมันคือสาเหตุที่พื้นที่เต็ม
(ดู `ANALYSIS.md` §9)

## การจัดกลุ่ม

**จัดกลุ่มให้เฉพาะสิ่งที่แบบบอกเองว่าเป็นชิ้นเดียว** — ไดเมนชั่นหนึ่งตัว
เครื่องหมายหน้าตัดหนึ่งอัน ลูกศรชี้หนึ่งอัน คลิกทีเดียวได้ทั้งชุด

**เรขาคณิตไม่ถูกจัดกลุ่มให้** เส้นที่นำเข้ามาเป็นชิ้นของตัวเอง
ถ้าต้องการยกทั้งวิว ให้ลากกรอบเลือกแล้ว Ctrl+Shift+G

> เคยมีการจัดกลุ่มอัตโนมัติโดยรวมเส้นที่เกือบแตะกัน (ห่างไม่เกิน 2.5 mm)
> เข้าเป็น "วิว" เดียว มันเดาผิดบ่อยพอที่จะกวน — ชิ้นส่วนที่แค่ผ่านใกล้กัน
> ถูกเชื่อมติดกัน — จึงถอดออก **การเดาที่ผิดบางครั้งแย่กว่าการไม่เดาเลย**

## โมเดลไดเมนชั่น

เก็บเฉพาะข้อเท็จจริงที่ไฟล์ยืนยันได้:

```js
{
  kind: 'linear' | 'aligned' | 'radial' | 'diameter',
  measure: { p1, p2 },      // จุดที่วัดจริง (linear/aligned)
  centre, radius,           // (radial/diameter)
  dir,                      // แนวการวัด
  line:  { q, arrow, arrowW, inside },
  ext:   { gap[2], overshoot[2], visible[2] },
  text:  { h, prefix, suffix, gapPx, side, align },
  land:  { len, off, side },   // radial: ความยาวเส้นชี้
  run:   { len },              // radial: ระยะเข้าหาศูนย์กลาง
  ok, dev                      // ผ่านการตรวจว่าวาดทับของเดิมได้ไหม
}
```

**ค่าที่แสดง = วัดจากเรขาคณิต แล้วจัดทศนิยมตาม Format Config**
ส่วนที่ห่อหุ้ม (`2x`, `⌀`, โน้ต) เก็บไว้ ตัวเลขเองไม่เคยถูกตรึง

**`ok` สำคัญ:** โมเดลจะถูกใช้ต่อเมื่อวาดทับของเดิมได้คลาด ≤ 0.35 mm
ถ้าไม่ผ่าน แปลว่าอ่านผิด → ปล่อยเส้นเดิมไว้ ไม่แตะ

## การระบุชนิด

ลำดับการตัดสิน (รายละเอียดใน `STYLIZE-RULES.md` §1b):

```
1. entity ประกาศตัวเอง (DIMENSION, HATCH, ARC…)  → เชื่อไฟล์
2. เลเยอร์ห้ามพิมพ์ (Defpoints)                    → ข้าม
3. ลายเซ็นเชิงรูปร่างของ section                   → เป็น section
4. เครื่องเรือนของกระดาษ (กรอบ/ตารางชื่อแบบ)        → ห้ามแตะ
5. นอกนั้น                                        → เนื้อแบบ
```

**section ระบุจากรูปร่าง ไม่ใช่ชื่อเลเยอร์** เพราะแต่ละโปรแกรมตั้งชื่อไม่เหมือนกัน
ลายเซ็น: หัวลูกศร 2 อันชี้ทางเดียวกัน (< 8°) · ห่างกัน > 15 mm ·
แนวเชื่อมตั้งฉากกับทิศ · มีตัวอักษรคู่ใกล้ปลาย (< 30 mm)

**เมื่อไฟล์ไม่ประกาศอะไรเลย** (แบบที่ระเบิดไดเมนชั่นทิ้ง) จุดยึดคือ**ตัวเลข** —
ตัวเลขบนแบบคือป้ายของการวัด และสิ่งที่ถูกวัดอยู่ข้าง ๆ มันเสมอ
กฎที่ตัดของปลอมออกคือ: **เรขาคณิตต้องตรงกับตัวเลขที่แบบเขียนไว้**

## การเขียน DXF

รูปแบบ **AC1009 (R12)** — อ่านได้กว้างที่สุด และทุกโครงสร้างที่ใช้อยู่ในสเปกจริง

| เขียนอะไร | ทำไม |
|---|---|
| ตาราง LAYER | ทุกชิ้นกลับไปอยู่บนเลเยอร์เดิม |
| ตาราง LTYPE | เส้นประ/เส้นศูนย์กลางเป็น**ชนิดเส้น** ไม่ใช่เส้นสั้นเรียงกัน |
| DIMENSION + definition point | ปลายทาง**วัดใหม่ได้** ไม่ใช่ text ที่พิมพ์ค้าง |
| BLOCK ต่อไดเมนชั่น | ตามที่สเปกกำหนด |
| DIMSTYLE override (XDATA) | บอกผู้อ่านที่สร้างใหม่ว่าให้วาดแบบเส้นชี้ |
| CIRCLE / ARC ของจริง | ไม่ใช่รูปหลายเหลี่ยม |
| `<>` เป็นค่าข้อความ | ให้ปลายทางวัดเอง ไม่ตรึงตัวเลข |
| `%%c` `%%d` `%%p` | control code ของ DXF สำหรับ ⌀ ° ± |

## การเก็บโปรเจกต์

**IndexedDB** (ถอยไป localStorage ถ้าใช้ไม่ได้)

- หนึ่ง record ต่อหนึ่งโปรเจกต์ — บันทึกอันที่ทำอยู่ ไม่เขียนอันอื่นใหม่
- ของเก่าใน localStorage ถูกย้ายให้อัตโนมัติตอนเปิดครั้งแรก แล้วปล่อยพื้นที่ 5 MB คืน
- โปรเจกต์จากบิลด์เก่าถูกทำให้ทันสมัยตอนเปิด: เติมช่องที่ขาด · fit วงกลมคืน ·
  สร้างโมเดลใหม่จากเส้น

- เคยลบผิดบล็อกมาแล้วหนึ่งครั้ง (`ANALYSIS.md` §10)
