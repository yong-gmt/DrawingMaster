# การทดสอบ

## ทำไมไม่มี unit test

บั๊กในโปรเจกต์นี้แทบทั้งหมด**ไม่ได้อยู่ในโครงสร้างข้อมูล** แต่อยู่ในเส้นที่วาดออกมา
ในไฟล์ที่เขียนออกไป หรือในสถานะที่เบราว์เซอร์เก็บไว้

การทดสอบทุกตัวจึงเปิดเบราว์เซอร์จริงผ่าน Playwright แล้ว **วัด** ไม่ใช่ assert เฉย ๆ
แต่ละตัวพิมพ์ตัวเลขออกมาให้อ่าน

```bash
node tests/t_model.js           # ตัวเดียว
bash scripts/test.sh            # ทั้งชุด (~63 ตัว, ใช้เวลาสักพัก)
bash scripts/test.sh sec        # เฉพาะตัวที่ชื่อมี "sec"
bash scripts/test.sh -q         # เอาเฉพาะที่พัง
```

ตัวรันไม่ได้เก็บรายชื่อเทสต์ไว้ — มัน**ไล่หา `tests/t_*.js` เอง**
รายชื่อที่เขียนมือจะล้าสมัยทันทีที่มีคนเพิ่มไฟล์ และเทสต์ที่เงียบ ๆ เลิกทำงาน
แย่กว่าไม่มีเทสต์

## สี่ระดับของการวัด เรียงตามความน่าเชื่อถือ

**1. ค่าในโมเดล — เชื่อได้น้อยที่สุด**
โมเดลเห็นด้วยกับตัวเองเสมอ ใช้ได้เฉพาะตอนตรวจตรรกะภายใน

**2. เส้นที่วาดจริง (primitives)**
สิ่งที่จะถูกวาดลงผ้าใบ จับได้ว่าโมเดลกับภาพไม่ตรงกัน

**3. พิกเซล**
สิ่งที่คนเห็นจริง จับได้ว่าธง bold หล่นหายตอนวาด ทั้งที่โมเดลถูกทุกอย่าง

**4. ไฟล์ที่เขียนออกไป อ่านโดยไลบรารีอื่น — เชื่อได้มากที่สุด**
`ezdxf` ไม่เคยเห็นแอปนี้ ถ้ามันวัดได้ตรง แปลว่าไฟล์เป็นแบบจริง ไม่ใช่ภาพของแบบ

## แม่แบบของเทสต์ที่ดี

```js
const {open, loadDxf} = require('./harness');
(async()=>{
  for(const dxf of ['Head-back.dxf','Body_Demo_Drawing_Sheet1.dxf','Body_Demo_Drawing_Sheet3.dxf']){
    const {b, pg} = await open('build/DrawingMaster.html');
    await loadDxf(pg, dxf);
    await pg.evaluate(()=>document.querySelector('#btnStylize').click());
    const r = await pg.evaluate(()=>{
      const h=window.__hook(), P=h.store.pages.find(x=>x.id===h.store.activeId);
      // อ่านจาก P.objects (สิ่งที่วาด) ไม่ใช่จาก P.dxf.dims (สิ่งที่โมเดลคิด)
      ...
      return { total, wrong, worstErrorMM };
    });
    console.log(dxf, JSON.stringify(r));
    await b.close();
  }
})();
```

**กฎ:** วิ่งกับ**ทุกไฟล์ที่มี** ไม่ใช่ไฟล์เดียว · รายงาน**จำนวนที่ผิด**ไม่ใช่แค่ pass/fail ·
ตั้งชื่อฟิลด์ให้อ่านแล้วรู้ว่าผิดอะไร

## เมื่อเทสต์เก่าพังหลังแก้โค้ด

ถามก่อนว่า **โค้ดผิด หรือเทสต์ถามผิด** ทั้งสองอย่างเกิดขึ้นจริงในโปรเจกต์นี้

- `t_drag`/`t_rt` เคยลากที่ "จุดใดก็ได้บนเส้น" ซึ่งเลิกเป็นจุดจับไปแล้ว → **เทสต์ผิด**
- `t_dec` บอกว่าค่าไม่ตามทศนิยม → **โค้ดผิด** (บรรทัดที่เรียกโมเดลถูกลบไป)

ถ้าเลือกไม่ถูก ให้ถ่ายภาพหน้าจอมาดู
