# สรุปงานที่ทำร่วมกันในเซสชันนี้

## จุดเริ่มต้น

แอปอ่าน DXF ได้ วาดได้ และ "จัดรูปแบบ" ด้วยการ**เดาจากรูปร่างของเส้น** —
เส้นไหนยาวที่สุดคือเส้นบอกระยะ ตัวไหนอยู่ใกล้ที่สุดคือตัวเลขของมัน
วิธีนี้ใช้ได้กับไฟล์ที่เคยเห็น และผิดทันทีที่เจอไฟล์อื่น

## สิ่งที่เปลี่ยนไป

**จาก "เดาจากเส้น" เป็น "อ่านเป็นโมเดล"**

ทุกไดเมนชั่น เครื่องหมายหน้าตัด และลูกศรชี้ กลายเป็น object ที่รู้ว่าตัวเองคืออะไร
วาดจากโมเดล ลากแก้ที่โมเดล และเขียนโมเดลกลับออกไปเป็น DXF ที่แก้ไขได้

| | ก่อน | หลัง |
|---|---|---|
| ไดเมนชั่นที่เข้าใจได้ | เดาจากเส้น | **86 จาก 87** ใน 3 ไฟล์จาก 2 โปรแกรม |
| เส้นที่วาดจาก "การเดา" | เกือบทั้งหมด | **0** |
| DIMENSION ในไฟล์ที่ export | **0** | **86** พร้อม definition point |
| วงกลม/ส่วนโค้งใน export | รูปหลายเหลี่ยม | **CIRCLE / ARC จริง** |
| ค่าที่แสดง | ตรึงเป็นข้อความ | วัดจากเรขาคณิต · ทศนิยมตาม config |
| เก็บโปรเจกต์ได้ | 8 แบบแล้วเต็มเงียบ ๆ | **20+ แบบ** บน IndexedDB |

## ความสามารถที่เพิ่มเข้ามา

- **สร้างไดเมนชั่นคืนจากแบบที่ไม่ประกาศอะไรเลย** — ระเบิด 33 ตัวทิ้ง แล้วสร้างคืนได้ **33/33 · ของปลอม 0**
- **เครื่องหมายหน้าตัด** ระบุจากรูปร่างไม่ใช่ชื่อเลเยอร์ · ทิศการมองอ่านจากไฟล์ ไม่คำนวณใหม่
- **ลูกศรชี้พร้อมหมายเลข** แก้เลขได้ วงกลมโตตามเลข ลากได้ทั้งสองปลาย
- **Add Text** ตัวใหญ่ · หนา · +2 pt
- **BOM** เลือกและลบได้ · ตัวอักษรเล็กกว่าที่ตั้ง 2 pt ยกเว้นหัวเรื่อง
- **ยกทั้งวิวด้วยคลิกเดียว** พร้อมไดเมนชั่นของมัน
- **เปิดโปรเจกต์เก่าแล้วใช้กฎใหม่ได้** — สร้างโมเดลคืนจากเส้นที่บันทึกไว้

## บั๊กที่พบและต้นเหตุ

อยู่ใน `ANALYSIS.md` ครบทุกข้อ ที่สำคัญที่สุด:

1. **export เป็นการไล่ตามรอยบนจอ** — ไม่มี DIMENSION สักตัว เลเยอร์เดียวทั้งไฟล์
2. **ส่วนโค้งเพี้ยนถึง 180°** — คำนวณมุมจาก transform แทนที่จะอ่านจากจุดที่วาด
3. **โปรเจกต์เก่าไม่มีโมเดล** — STYLIZE จึงไม่มีอะไรให้ทำ ดูเหมือนไม่ได้แก้อะไรเลย
4. **localStorage เต็มเงียบ ๆ** — 56% ของที่บันทึกคือของที่สร้างคืนได้อยู่แล้ว

## ชุดทดสอบ

~48 ตัวที่เป็นชุดหลัก ทุกตัวขับเบราว์เซอร์จริงและ **วัด** ไม่ใช่แค่ผ่าน/ไม่ผ่าน
ที่จับบั๊กได้จริงเกือบทั้งหมดวัดสิ่งที่อยู่**นอกโมเดล** — พิกเซล ไฟล์ที่เขียนออกไป
หรือสถานะของเบราว์เซอร์
